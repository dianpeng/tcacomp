# Phase 01.1 Plan 01: IR Architecture Refinement Summary

**Type-as-interface with interned NumericType, SSAVar handle model (SSADef/SSAUse value handles over ref records), Value/NoneValue interface, and a Descend/SkipChildren/Stop visitor Walk — all with byte-identical goldens and zero out-of-package caller breakage.**

## Accomplishments

- **Directive 1 (types):** `Type` is an interface (`Equal(Type) bool` only); `NumericType` is the concrete component with unexported fields; interning preserved (interface `==` is identity for numerics); `Equal` is the future cross-component comparison point. pkg migrated via one `numericOf` helper.
- **Directive 2 + 4-core (SSA handles):** per-node `SSAVar` pointee allocated 1:1 at node allocation (ID == node ID, IR-05's single NewID source preserved); `SSADef`/`SSAUse` are value-type handles over `{def,user,killed}` ref records — rewiring a record propagates through every handle copy. The five `MutContext` choke points reimplemented over handles with identical guard behavior and error strings; all stamp `LastTouchedBy`.
- **Directive 3 (Value + walk):** `Value` is a real interface (`Node` + `IsNone`); `returnNode` is the none root; `Statement.Value()` is the sole classification accessor. `ir.Walk` is iterative pre-order DFS with a visited set (cyclic-safe), `VisitResult` gives Descend/SkipChildren/Stop; verify and pass legality migrated.
- **Verifier:** both chain directions over ref records with unchanged `Violation` type, `String()` format, invariant names, and diagnostic richness; killed-record and zero-handle operand slots are new use-def subclasses with slot-named messages.
- **Boundary contracts held:** irx_test.go and the six out-of-package AddStatement callers received zero edits in Wave 2; goldens byte-identical across all waves; determinism stable x5.

**1. [Rule 3 - Blocking] print_test.go case struct would not compile under the Type interface**
- **Found during:** Task 1 (GREEN)
- **Issue:** The print test table held `typ *Type` fields; once Type became an interface, the struct needed `typ Type` plus an assertion at the call site — the package could not compile without it.
- **Fix:** `typ *Type` → `typ Type` in the test case struct; assertion fix at use. No rendering change.
- **Files modified:** internal/ir/print_test.go
- **Verification:** print goldens byte-identical
- **Committed in:** `278af69` (Task 1)

**2. [Rule 2 - Missing Critical] nodeImpl needed a fourth hook: setSlot**
- **Found during:** Task 3 (GREEN)
- **Issue:** The plan's D-6 hook list named forEachOperand/addSlot/removeSlot, but construct.go's wireOperands must write a wired handle into an EXISTING slot index at construction time; no listed hook could do that without bypassing the node abstraction.
- **Fix:** Added unexported `setSlot(u SSAUse, i int)` to the nodeImpl hook family alongside the three planned hooks; construct and mutation both route through it.
- **Files modified:** internal/ir/node.go, internal/ir/construct.go
- **Verification:** structural grep + Task 4 full-suite gate
- **Committed in:** `d3be695` (Task 3)

**3. [Rule 1 - Bug] SetDef same-var early-return skipped LastTouchedBy stamping**
- **Found during:** Task 4 (GREEN) — the RED test for stamp behavior caught it
- **Issue:** An early-return on "record already in target var" bypassed the stamp, violating D-17 (every choke point stamps LastTouchedBy on the same node set as before).
- **Fix:** Stamp unconditionally before the early return; physical record move unchanged.
- **Files modified:** internal/ir/mutate.go
- **Verification:** failing stamp test passes; suite green
- **Committed in:** `b9c6695` (Task 4)

**4. [Rule 1 - Bug] Task 5 RED test expectation for SkipChildren was wrong**
- **Found during:** Task 5 (GREEN run)
- **Issue:** Expected `[3 7 6 5]` assuming skipped sum's operands a/b become globally unreachable; in fact b is also the map's operand and a appears in the lambda body, so they remain reachable via other edges. Got `[3 7 2 6 5 1]`, which is the correct SkipChildren semantics (prune the skipped node's subtree edges only).
- **Fix:** Corrected the test's want and comment; no implementation change.
- **Files modified:** internal/ir/walk_test.go
- **Verification:** suite green; semantics now pinned
- **Committed in:** `fa09d95` (Task 5)
