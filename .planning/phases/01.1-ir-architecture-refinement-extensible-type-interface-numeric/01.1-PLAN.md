D-1 (interning under the Type interface), resolved:
```go
// internal/ir/types.go
type Type interface {
    Equal(other Type) bool
}

type NumericType struct { /* elem ElemType; dims []DimRef — unexported */ }

func (t *NumericType) Elem() ElemType
func (t *NumericType) Rank() int
func (t *NumericType) IsScalar() bool
func (t *NumericType) Dims() []DimRef          // copy, as today
func (t *NumericType) Equal(other Type) bool   // content compare numeric↔numeric; false for non-numeric

func InternScalar(elem ElemType) Type          // was *Type
func InternTensor(elem ElemType, dims []DimRef) Type
```
Rationale: interning table mechanics unchanged (FNV content hash, lookup-only,
never iterated). Interface `==` is identity because the dynamic type
`*NumericType` is a comparable pointer and interns are deduped — all current
pointer-equality sites (`x.typ != y.typ` in pkg, `lhs.Type() != InternTensor(...)`
in irx_test) keep working unchanged on the interface. `Equal` is the
cross-component comparison point for future tuple/struct types. Consumers
needing elem/dims type-assert: `nt, ok := t.(*ir.NumericType)`. A nil or
non-numeric type renders as `?` in typeText (deterministic; verifier owns
rejection) — the printer's numeric paths are never touched by future
components. Param.typ, constNode.typ, castNode.typ all become `Type`.

D-2/D-3 (Value / NoneValue / SSAVar ownership), resolved:
```go
// internal/ir/node.go — Value is a real interface; NoneValue semantics via IsNone
type Value interface {
    Node
    IsNone() bool
}
func (b *Base) IsNone() bool { return false }        // promoted to every node
func (*returnNode) IsNone() bool { return true }     // the none root: a Value, but nothing
```
Rationale: every current node kind except return produces a referenceable
value (store DOES — doc §2.5 "store returns the stored value"; it is the
operand of the builder's return binding and prints as `%output`). Return is
the statement root that binds no SSA name: it satisfies Value so it can sit
in a statement RHS slot, and `IsNone()` reports the none semantics. This is
exactly "a none Value is a Value but just nothing". `Statement` keeps
`RHS() Node` and gains `Value() Value` (rhs as Value). A future explicit
`noneValue` sentinel can join without touching NumericType-era code.

SSAVar ownership: per-node, one SSAVar per node, allocated at allocNode time,
ID == node ID (1:1, no separate counter — IR-05's single NewID source is
preserved verbatim and statement numbering cannot drift).

D-4 (clean break): internal APIs break freely; no compat shims; every call
site in-repo is migrated in the same task that breaks it.

D-5 (visitor shape + walk-order resolution), resolved:
```go
// internal/ir/walk.go
type VisitResult int
const ( Descend VisitResult = iota; SkipChildren; Stop )
type Visitor interface{ Visit(Node) VisitResult }
type VisitorFunc func(Node) VisitResult
func (f VisitorFunc) Visit(n Node) VisitResult { return f(n) }
func Walk(g *Graph, v Visitor)
```
Walk is iterative pre-order DFS with a visited set (cyclic-safe, no recursion):
roots in BB statement order (def when valid, then rhs); children of a node in
operand-slot order (live records only), then lambda bodies. `Descend` enqueues
children, `SkipChildren` prunes the subtree, `Stop` terminates the walk.
Rationale on print/dot: the printer's `StmtNodes` DFS is an EMISSION-order
function (chain stages producer-first via pipeInput — an order that is not
expressible as a graph-edge walk), and its order is golden-pinned. Migrating
print/dot to Walk would change golden bytes, which the hard constraints
forbid. So verify and legality migrate onto Walk; StmtNodes stays the
printer's canonical-order enumerator, sharing the same operand/lambda child
primitives. This is the maximal migration that preserves byte-identical
goldens; it is recorded here so the phase summary can cite it.

D-6 (MutContext over handles), resolved:
```go
// internal/ir/ssa.go — seabird mechanics adapted (pattern, not code)
type SSAVar struct { /* id; node Node; define Value; refs []*ssaRefRecord — unexported */ }
func (v *SSAVar) ID() uint64
func (v *SSAVar) Node() Node            // back-pointer (nil-safe on zero var)
func (v *SSAVar) Define() Value         // nil-safe
func (v *SSAVar) RefSize() int          // LIVE (non-killed) records only
// replaceDefine / replaceAllReference are unexported: reachable only via MutContext.

type SSADef struct { ssa *SSAVar }      // value-type handle
func (d SSADef) SSA() *SSAVar           // nil-safe: zero def → nil
func (d SSADef) IsInvalid() bool        // ssa == nil (replaces "def == nil" checks)
func (d SSADef) Define() Value          // nil-safe

type SSAUse struct { rec *ssaRefRecord } // value-type handle; copies share the record
func (u SSAUse) SSA() *SSAVar            // nil-safe: zero use → nil
func (u SSAUse) IsKilled() bool          // zero use, killed record, or nil target
func (u SSAUse) Def() Node               // def node back-pointer, nil-safe

// ssaRefRecord (unexported): { def *SSAVar; user Node; killed bool } —
// pointer-to-pointer indirection: rewiring sets rec.def = newVar and EVERY
// copy of the SSAUse (each operand slot holds one) sees the new target.

func UsesOf(def Node) []SSAUse   // snapshot, link order; nil def → nil
func DefOf(u SSAUse) Node        // was DefOf(*Use) Node
```
nodeImpl hooks become `forEachOperand(fn func(SSAUse))`, `addSlot() SSAUse`,
`removeSlot(u SSAUse) bool` (compares record pointers). `operandList.ops`
becomes `[]SSAUse`. Unwired slot = zero SSAUse (rec == nil). The old
`Use` struct, intrusive prev/next links, and `linkIntoDef`/`unlinkFromDef`
are DELETED. Killed/zero handles are representable but checkable — the
verifier flags them structurally (new use-def sub-checks: killed record used
as operand; zero-value handle in a slot reports the same "nil def (unwired
operand)" message as today).

// internal/ir/mutate.go — same five choke points, handle-based signatures:
func (ctx *MutContext) SetDef(u SSAUse, newVal Node) error   // reject zero u
func (ctx *MutContext) AddUse(user, val Node) SSAUse         // zero SSAUse on failure
func (ctx *MutContext) RemoveUse(u SSAUse)                   // kill record + drop slot
func (ctx *MutContext) ReplaceAllUsesWith(old, newVal Node) error
func (ctx *MutContext) Erase(n Node) error
```
All five stamp LastTouchedBy exactly as today (D-17). SetDef physically moves
the record old→new var. RAUW walks a snapshot of old's live records and
rewires each into newVal's var (self-RAUW no-op, nil guards preserved). Erase
refuses while RefSize > 0, kills its own operand records, drops statements
holding n, tombstones (IR-05). The WR-01 surplus-operand construction check
is untouched (Base.surplus stays).
