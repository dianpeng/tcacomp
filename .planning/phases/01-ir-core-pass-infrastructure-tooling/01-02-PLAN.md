## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-02-01 | Tampering | Unknown node kinds introduced by future passes slipping through verification | mitigate | Legality map-presence policy rejects any Kind absent from the window's Actions map, plus KindInvalid and >= KindEnd, after EVERY pass — future kinds below KindEnd fail CLOSED (Pitfall 8); TestLegalityRejectsUnknownKind pins both cases (IR-03) |
| T-1-02-02 | Denial of Service (analog) | Partial pipeline state after a pass failure | mitigate | Run aborts on first error with "pass %s: %w" / "pipeline end: %w"; no subsequent pass executes (MLIR-verified semantics) |
| T-1-02-03 | Information leakage (analog) | Pass-timing/dump output contaminating golden or stdout streams | mitigate | All instrumentation writes go to the io.Writer field (default os.Stderr); never stdout; goldens capture printer bytes only (Pitfall 6) |
| T-1-02-04 | Repudiation (analog) | Verification skipped silently | mitigate | VerifyEach defaults ON and runs both per-pass (AfterPass) and once at pipeline end (AfterPipeline) — an empty pass list is still verified; --verify-each=0 is an explicit opt-out read from flags.F (TOOL-06); TestPipelineEndErrorSurfaces proves the gate and the empty-pipeline path |
