<r3_spec>
THE load-bearing spec text (fix5.md §1 R3 ruling, amended session-2, is normative; this is its operational form):

R3 ranking — computed ONCE per LNT over the search window, in searchScheduleStats, BEFORE the per-dim digitListOf loop; the single winner dim is the only dim whose digit list carries a WARP section.

Order window dims by these levels, in order (the comparator is TOTAL — it must always resolve, never panic, never leave a tie):
- L1: effective extent DESC — constExtentOf const value, else Params.NominalExtent (the SAME effective-extent discipline as R1's adaptiveLoC and R4's reducedTierEff).
- L2: stride-1 set membership first — stride1Set = the union over lf.CS sites of the iters at the site's INNERMOST subscript position (the last non-empty AxesIters entry of each candidate load — the coalescing axis); dims in the set rank above dims not in it, and WITHIN the set, innermost window position first.
- L3: non-reduced before reduced (the "reduced axis as last-resort fallback" demotion — it only fires on residuals L1/L2 left tied).
- L4: innermost window position (final total fallback — window order is unique, so this always resolves).

digitListOf gains the winner (e.g. a `warpDim ir.Node` parameter): the WARP preset section AND the R1 adaptiveSection(SoCWARP) emit ONLY when iter == warpDim, and the existing R-REDUCED prune stands on top (winner reduced && !Params.ReducedDimWarp → no WARP section for that LNT at all).

Worked outcomes the pins MUST reproduce (derivations in pin comments):
- Suite matmul shape (lhs[i][k], rhs[k][j], reduce over k, ALL dynamic): L1 ties {i,j,k} → L2 stride1Set = {k (lhs innermost), j (rhs/store innermost)} → within-set innermost window position → k (reduce innermost) → warps-on-K → split-K preserved (family-B).
- Frontend fixture (const feM=64, feN=128, feQ=64, reduced=N): L1 → N (128 largest) → warps-on-reduced-N → fePinScheduleSignature UNCHANGED.
- scale_copy shape (dynamic r,c tie at stand-in; reduced k const 4): L1 eliminates k → {r,c} → L2: stride1Set from the 3D loads is {k} → both out (or c, if a 2D [r,c] load/store is in the site set — either way) → L3 both non-reduced → L4 innermost among {r,c} → c → warps-on-C, K=SEQ → the T1 collapse vector wins, ceremony vector UNREPRESENTABLE.

- ≤1 WARP dim per LNT henceforth (multi-warp-dim vectors leave the feasible area); MAPM/MALoC accounting unchanged. This NARROWS the kzv surviving-WARP unruled case-b reach — a side benefit, one line.
