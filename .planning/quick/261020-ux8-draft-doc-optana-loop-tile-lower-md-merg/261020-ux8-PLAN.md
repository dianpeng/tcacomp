      - Reference doc/optana/loop_tiling.md's revised templates (tile-id

        (c) emit LIR KindForLoop for every generated loop so the NEXT pipeline

      §4 Predication Discipline (parallel tails)
      - Model: CTA-uniform trip counts + predicated tails (one-BB constraint —
        the compiler NEVER emits branches).
      - Canonical form per parallel tile-inside loop:
        iters = ceil(a_tile_max / nThreads)   // CTA-uniform
        for (it = 0; it < iters; it++) {      // same count every thread
          base = it * nThreads                // uniform
          idx  = a_tile_offset + base + lane  // per-thread
          active = (base + lane) < a_tile_max // per-thread predicate; folds
                                              // tile bound AND global extent
                                              // (a_tile_max already clamps)
        }
      - Wrapping rules by node family:
        (a) pure value computations → KindSelect(active, value, undef)
        (b) GMEM effects → runtime bounds-checked tile variants (loadtile/

            expressed as value selection — direct unguarded stores in parallel

        (c) collectives (reducer Init/Combine, cooperative tile ops) → called

            contribute identity (runtime-internal)
        (d) whole-warp groups → active/inactive is a clean lane mask; no

            warp-multiples)

      - Buffer materialization: MemNewSMem / FragNew allocation sites at each
        promoted site's tie level; extents from the covered tile shapes AFTER
        demotion (Cache.dims trailing dimensions); StorageClass payload.
      - Copy variant selection: dims covered by cta_for/thread_for → SMEM
        cooperative LoadTileCta; dims under seq_for → FRAG LoadTileThread.
      - Sync: the runtime owns ALL synchronization — this pass NEVER emits
        barriers; visibility/reuse-safety/store-ordering are runtime contract
        items, compiler obligations are the uniform-call rule + bounds.
      - Budget enforcement: Σ SMEM bytes ≤ Max.cache; FRAG sites additionally
        require the tile FULLY UNROLLS (register arrays spill to local memory
        when indices are not compile-time constants after unrolling — a
        non-unrolled FRAG tile is strictly worse than the GMEM load replaced)
        and a per-thread FRAG byte budget (× threads/CTA) beside Max.cache.
      - Fallback (selection never fails): halve the reuse tile sizes, then
        drop sites back to GMEM.
      - Post-pass epilogue: relies on the pipeline's typeinfer re-run for
        newly inserted lowered nodes (idempotent) — which REQUIRES §5's
        typeinfer rules to exist.

      §7 Policies
      - Dynamic shapes: tile/group sizes are compile-time constants; extents
        may be runtime values, handled by remainder guard + §4 predication.
      - Cross-LNT sites: dedupe kernel-wide by MemLoad node identity; a load
        whose INS spans multiple LNTs is evaluated against the UNION of the
        referenced iters' assignments; never-bucketed loads are declared
        non-candidates.
      - Determinism: DoSoC numbering order (outer→inner per LNT) and preset
        ordering inherited from the decide pass; this pass adds no search.
      - Re-typing: see §6 epilogue.

        destroyed at LNT exit; next LNT constructs its own remap. The 1-D

      - Linearization (multi-dim remap of the 1-D launch) is runtime-owned;
        the compiler never inlines its own copy.
      - Tile-op obligations: visibility (SMEM writes visible to the CTA after

        effect-guarding physically lives), uniform call.
      - Launch/budget validation at runtime: grid = ceil(ext/T); device-
        attribute queries for SMEM budget — never hardcode sm_86 ceilings

        runtime files; it does not drive nvcc.
