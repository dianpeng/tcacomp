Key facts (doc/ir.md 6-7, internal/ir/dce.go):
- R3 two-root set: Level-1 liveness roots = the end node (`KindReturn`, carrying return values + every mem-param's final chain head via ImpactBy) plus the params. Effectful nodes are NOT roots — a store no end path reaches is dead.
- `EffectOf`: only `KindMemStore` (GMEM) + `KindReturn` are EffectFull. SMEM/FRAG stores and ALL loads are free (in-program memory, dead-code-eligible). `KindMemNew`/`KindMemNewSMem`/`KindFragNew` are effect-free allocations — swept when unreachable (user requirement 5).
- The Level-1 mark walk roots at ALL params + end (not just RoleTensor) deliberately: params are graph-owned signature nodes whose ref lists the def-use checker audits, so the sweep must never erase them. `ir.Walk`'s Level-1 root set is exactly this — the pass reuses Walk instead of duplicating markReachable.
