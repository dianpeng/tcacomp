## Author rulings (2026-10-21 — LOCKED, do not revisit)

- **R1 Fill placement (fixes CR-02, HI-01, HI-02):** fill position is variant-dependent.
  `LoadTileThread` fills inside the element loop that defines its per-thread coordinate
  (refill per epoch of the fill key, e.g. lhs refills per m-element inside M.inside).
  `LoadTileCta` fills at the innermost covered dim's between-round body with
  CTA-UNIFORM coordinates only (round bases). One structural splice mechanism, no
  `bodyRoot == load` special case.
- **R2 WARP-dim SMEM = rank-in-index (fixes HI-03; author's ruling, verbatim intent):
  "the access for that memory index inside of the tile must use the runtime object
  thread_map.index(d), to obtain its thread index mapping for that dimension; if that
  dimension is a SEQ based SoC, it is a sequential tile loop."** Consequences:
  - SMEM buffer extent per covered WARP dim = `#threads_d × tile_size` (the group
    window); SEQ dims = `tile_size`. (Rank-in-index ⇒ window-in-shape.)
  - Access index on a WARP dim = `thread_map.index(d)·T + i` where `d` = that dim's
    slot in the LNT's ThreadMap (one map per LNT, tuple coordinates) — NOT a hardcoded 0.
  - Fill = one cooperative `LoadTileCta` per round, CTA-uniform base, disjoint stripes,
    tail clamping inside the loader.
  - Tier rule (rule 2, restated): covered dims contain CTA → refuse site; contain WARP →
    SMEM window; all SEQ → FRAG (per-thread; fill key per-thread, e.g. lhs→FRAG).
  - Accepted consequence: rhs at the worked example needs a 1 MB window vs the 64 KB
    budget → budget fallback declines it at default shapes. The flagship example shows
    lhs promoted (FRAG 128 B) and rhs declined. This is intentional.
- **R3 SMEM budget scope (fixes HI-06):** kernel-wide. Decide accumulates across LNTs;
  tiling-verify and resolveBudget gate the same kernel-wide sum.
- **R4 Cross-LNT loads (fixes ME-03):** fail-closed for v0. Loads whose INS spans ≥2
  LNTs get explicit non-candidate SiteDecision entries in the record (Promoted=false,
  reason); the rewrite refuses to rewrite bodies referencing foreign iters.
- **F1 tail guard formulation:** `off′ = umin(offset, extent); tile_max = umin(T, extent − off′)`
  — pure u32, wraps nowhere, `tile_max == 0` exactly when out of range.
- **F6 constant:** new `MaxFragPerThread` param, default **256 bytes/thread**.
