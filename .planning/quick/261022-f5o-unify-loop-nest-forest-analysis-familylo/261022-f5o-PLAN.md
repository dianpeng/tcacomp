internal/analysis/loopforest and the schedule pass's private LIR forloop LFA

DEPTH-BASE RULING (D-02, decided here by minimal ripple): the unified
analysis convention is **root depth = 0** — exactly today's loopforest
convention. Rationale: (1) loopforest_test.go pins Depth==0 in four tests and
the decision requires existing suites green UNMODIFIED where possible;
(2) every tiling Depth use is RELATIVE (overlap.go `node.Depth > bestDepth`,
levelsInnerToOuter sort, lower_rewrite `bestDepth := -1` comparisons) so a
uniform shift would be invisible, while an absolute shift buys nothing;
(3) the scheduler is the ONLY absolute-depth consumer (anchors SN at depth,
byDepth map keys) and it already adapts through nest.go — so the +1 mapping
lives at that single adapter point. Document this ruling in BOTH the LFA
header comment and nest.go.
