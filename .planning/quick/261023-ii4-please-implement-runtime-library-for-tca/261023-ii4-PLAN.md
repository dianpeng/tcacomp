Namespace layout: everything device-side lives in `tca::rt::`; the host
launcher type is `tca::Tensor<T, Rank>`. All index-shaped values are `unsigned`
(u32).

1. KernelInfo — dual-compile pattern (so mapping math is CPU-testable):
   members none on device; accessors `total_cta()` / `total_thread_per_cta()`
   are `__host__ __device__` and read `gridDim.x` / `blockDim.x` under
   `#if defined(__CUDA_ARCH__)`, else (host g++ or nvcc host pass) return
   members `ctas_` / `threads_` that a host-only explicit ctor
   `KernelInfo(unsigned ctas, unsigned threads)` (guarded
   `#ifndef __CUDACC__`) sets; host default ctor zeroes them. Device default
   ctor stays `= default` (the golden constructs `tca::rt::KernelInfo kinfo;`
   in device code and that must remain valid).

2. Host-compilation shim — at the top of mapping.h, iterator.h, view.h, and
   reducer.h (the headers CPU tests include), guarded so it applies exactly
   once per TU: when `__CUDACC__` is NOT defined and a sentinel
   `TCA_HOST_SHIM` is not yet defined, define `__device__` and `__host__` as
   empty macros. These four headers must otherwise include no CUDA headers.
   Device-only constructs (`__shared__`, `__shfl_down_sync`,
   `__syncthreads__`, `__trap__`) appear only inside
   `#if defined(__CUDACC__)` regions (loader.h, the WarpReducer/GlobalReducer
   bodies in reducer.h) — those two headers are nvcc-only for the device
   parts; loader.h is never included by CPU tests.

3. Mapping decomposition (rt.md §4.2, corroborated by runtime_objects.md
   §1.4 + §2.2 — "per-thread rank", "thread LoC", "cuda_linear_id first,
   then reverse stride-shape decomposition"):
   - GridMapping(KernelInfo, int... portions): total = kinfo.total_cta();
     kPortionCTA = 10; Q = total / 10. extent_d (in CTAs) = portion_d * Q
     for concrete portions; the `-1` tail (last only) = total − Σ(other
     extents). dimension(d) = extent_d. index(d) = coord_d where coords
     decompose blockIdx.x row-major over the extents (last dim stride 1):
     coord_d = (blockIdx.x / stride_d) % extent_d.
   - ThreadMapping(KernelInfo, int... portions): total_warps =
     kinfo.total_thread_per_cta() / 32; kPortionWarp = 8; Q_warps =
     total_warps / 8. extent in warps = portion_d * Q_warps, `-1` tail =
     total_warps − Σ(other warp extents). Exposed in THREADS:
     dimension(d) = warp_extent_d * 32; index(d) = coord_d from decomposing
     threadIdx.x row-major over the thread-granular extents.
   - Golden check values (pin these in unit tests): ThreadMapping(4, -1)
     with 512 threads → dimension(0) = 256, dimension(1) = 256, index(0) =
     (tid / 256) % 256, index(1) = tid % 256. GridMapping(-1) with 100 CTAs
     → dimension(0) = 100, index(0) = blockIdx.x.
   - Constructor validation: each portion ≥ 1 or exactly −1, −1 only last,
     at least one portion — violate → assert-style trap (a tiny internal
     Check mapping to assert() on both host and device; no exceptions on
     device paths).
   - Variadic ctor: `template <typename... P> GridMapping(KernelInfo, P...)`
     accepting int literals; ndim implied by argument count.

4. Iterator walk (rt.md §4.3; ctor arg order verified against the emitter
   internal/cg/cxx/loops.go: map, dosoc, LoC, init, step, bound — init/step
   are dimvar literals, bound is the emitted saturating-chain expression):
   all three types walk identically: state `base_ = init`; `Has()` returns
   `base_ < bound`; `Next()` does `base_ += step`; `Index()` returns
   `base_`. Has() is CTA-uniform by construction (init/step/bound uniform).
   CtaIterator/ThrIterator store map, dosoc, loc as members and ignore them
   in v0 (future ownership-guard queries). Signatures take the mapping by
   const reference; construct from the golden shapes:
   SeqIterator(unsigned, unsigned, unsigned);
   CtaIterator(const GridMapping&, unsigned dosoc, unsigned loc, unsigned
   init, unsigned step, unsigned bound); ThrIterator(const ThreadMapping&,
   same tail).

5. Views (rt.md §4.4): `enum class Layout : unsigned { RowMajor = 0 };`
   - TensorView<T, Rank>: ctor (T* data, unsigned dims...); row-major
     strides computed at construction. Get(coords...) is bounds-PREDICATED:
     any coord ≥ its dim → return T{} (suppression — never a wild access);
     Set(v, coords...) silently no-ops when out of range. T may be
     const-qualified (goldens instantiate TensorView<const float, 2u>).
   - SmemView<T, Rank>: ctor (T* base, unsigned extents...); Get/Set
     unchecked (in-window by construction), same row-major stride math.
   - Frag<T, Rank, Dims...>: register tile with the same Get/Set face,
     extents from Dims; not exercised by the goldens but part of the
     registered surface — keep minimal and compiling.

6. umin/umax: `__host__ __device__ unsigned umin(unsigned, unsigned)` and
   umax — plain comparisons (host-annotated so CPU tests pin them).

7. Loaders (rt.md §4.5, nvcc-only header):
   template over both view types, e.g.
   LoadTileCta(SmemView<ST, DR>& dst, const TensorView<GT, SR>& src,
   unsigned baseCoords...) — note src's T is const-qualified in the golden.
   Window contract: dst covers the source tensor's TRAILING dst.Rank()
   axes; baseCoords carries one coordinate per source axis in order
   (trailing axes = round bases, leading axes = fixed coords).
   Enumeration: windowElems = product of dst extents; stripe over the CTA:
   for (i = threadIdx.x; i < windowElems; i += blockDim.x); decompose i
   row-major over dst extents into window coords w; source point = base
   with each trailing axis j offset by w[j − (SR − DR)]; read via src.Get
   (its bounds suppression IS the tail clamp — padding content safe);
   dst.Set(value, w...). Ordering contract: one __syncthreads() BEFORE the
   copy loop (refill write-after-read wait) and one AFTER (visibility) —
   v0 plain-copy, no cp.async (optional fast path is explicitly internal/
   future; leave a one-line comment noting the arch-guarded hook).
   LoadTileThread(Frag&, const TensorView&, baseCoords...): same window
   math, single-thread copy loop, no synchronization.

8. Reducers (rt.md §4.6) — CRITICAL signature ruling: the golden passes a
   function-template NAME (`RedwarpCombine0`) as the combiner argument, so
   the ctor parameter must be the concrete function-pointer type
   `T (*fn)(T, T)` (template-argument deduction against a function template
   name requires a concrete target type; a deduced `F&&` will NOT compile
   the golden). Store the pointer; the runtime owns every combiner call.
   - State: `T acc_[Slots > 0 ? Slots : 1]`; `Init()` fills with the
     construction-time init; `Combine()` is called once per bracket.
     Slots semantics: the flat accumulator-tile extent the compiler stamps
     as the template argument; the runtime sizes all state from it. v0 slot
     addressing is FLAT: `Reduce(unsigned slot, T v)` when Slots > 0 (the
     goldens pass exactly one index; a multi-dim slot space would be
     linearized by the compiler — a compiler-visible signature change if
     ever needed), and `Reduce(T v)` when Slots == 0.
   - Combine() return: `T` when Slots == 0; otherwise `SlotValue<T, Slots>`
     with `Get(i)` (implement as `auto Combine()` with `if constexpr
     (Slots == 0)`; SlotValue is a thin array wrapper with Get(unsigned)).
   - SeqReducer: fully `__host__ __device__`, no synchronization; Combine
     returns the local accumulators (copy) — CPU-testable.
   - WarpReducer (nvcc-only body): (1) Init/Reduce on the private tile as
     above; (2) Combine(): per slot, full-warp shuffle down-tree with
     `__shfl_down_sync(0xffffffff, ...)` over offsets 16,8,4,2,1 (valid
     because inactive lanes hold the identity init); lane 0 of each warp
     stages its per-slot partials into static scratch; `__syncthreads()`;
     every thread then folds ALL staged partials per slot locally in
     ascending warp order (the replicated-local-combine broadcast — every
     participant receives the final value). (3) Scratch = the ruling:
     function-scope `static __shared__` array inside the template member:
     `T stage[Slots > 0 ? Slots : 1][kMaxWarpsPerCTA]` with
     kMaxWarpsPerCTA = 16 (512/32 default config); over-provisioned vs the
     group's warps by design (warps outside the group stage the identity).
     Deterministic fold order everywhere (ascending warp id).
   - GlobalReducer: compiling stub only, same face; bodies trap at runtime
     (`assert(!"GlobalReducer: not enabled in v0")`-style via the internal
     Check helper); no static_assert (must compile if ever instantiated).

9. Host surface (rt.md §5):
   - check.h: `[[noreturn]] void Throw(const char* what)` throwing
     std::runtime_error; `TCA_REQUIRE(cond, what)` → Throw with a
     file:line prefix plus what; `TCA_CUDA_CHECK(expr)` evaluating expr,
     Throw with cudaGetErrorString + file:line on non-success (scalfold
     CUDA_CHECK style — see
     /home/ps/Workspace/cuda/project/scalfold/example/tinyllama/cuda_check.h
     for the reference shape).
   - tensor.h: `template <typename T, unsigned Rank> struct Tensor` —
     non-owning (T* data + unsigned dims[Rank] + Layout, RowMajor in v0);
     static `From(T* data, dims...)`; `Data()`, `Dim(axis)`, `Rank()`
     (careful: the method name collides with the template parameter —
     return a private `static constexpr unsigned kRank` copy), `layout()`.
   - launch.h: `void ValidateLaunch(dim3 grid, dim3 block, unsigned
     smemBytes)` — TRAP (Throw), never clamp: grid.x > 0 and a multiple of
     PortionCTA=10; block.x a multiple of 32 with warp count a multiple of
     PortionWarp=8; block.x ≥ 256; smemBytes ≤
     cudaDeviceGetAttribute(cudaDevAttrMaxSharedMemoryPerBlockOptin) − 1024
     (the reserved-per-block bytes, per rt.md §5's wording; conservative
     direction — the 64 KB v0 budget passes comfortably; NEVER hardcode
     sm_86's 101,376). Query failure → Throw. Comment that reducer static
     scratch shares the same per-block ceiling enforced by the driver at
     launch and surfaced through TCA_CUDA_CHECK.
   - runtime.h: includes cuda_runtime.h, cuda_fp16.h, cuda_bf16.h and all
     nine tca/*.h — the only include generated code uses.

10. CMake (rt.md §1): runtime/CMakeLists.txt —
