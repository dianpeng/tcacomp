# Quick Task 261021-ta3: Implement the final optimization pass schedule (AST-style CFG + LICM)

Implements doc/optana/schedule.md: the combined pass that brings the Level-1
sea-of-nodes back to an AST-style CFG (Kernel → Group/Loop blocks) with
scheduling-number LICM, replacing the obsolete statement-level schedule pass.
The output AST CFG is consumed LASTLY by final_lower and code generation.

**Design spec (follow strictly):** `doc/optana/schedule.md`
**Consumer contract (do not implement — read for shape constraints):** `doc/optana/final_lower.md`
**Pipeline slot:** `doc/opt.md` (scheduling → final lower, the last optimization pass)

## Locked decisions (from discuss-phase — NON-NEGOTIABLE)

1. **Placement (D-01):** the AST CFG lives as a SEPARATE NEW field on `ir.Graph`
   (`g.ast`). The legacy single-block `cfg`, `Materialize`, the canonical
   printer, and all goldens are UNTOUCHED.
2. **Old pass (D-02):** `internal/opt/schedule/scheduler.go` (statement topo +
   LICM on the materialized block) is REMOVED ENTIRELY and rewritten from
   scratch; `scheduler_test.go` goes with it.
3. **Persistent per-node scheduling info (D-03, user emphasis):** each node's
   SN AND its SN→block linkage must be STORED ON the IR nodes (fields on
   `ir.Base`), because final_lower (and reducer lowering) consumes them AFTER
   scheduling. Not throwaway pass-local maps.
4. **Scope (D-04):** the pass builds block structure, assigns nodes to blocks
   via SN ranks, and topologically orders nodes within each block (data deps
   via Input, effect deps via ImpactBy). It does NOT insert
   runtime-object/glue nodes (KernelInfo, GridMapping, reducer Init/Combine —
   final_lower's job per final_lower.md). Empty Group prologue/epilogue blocks
   ARE created per spec (landing pads final_lower later fills).
