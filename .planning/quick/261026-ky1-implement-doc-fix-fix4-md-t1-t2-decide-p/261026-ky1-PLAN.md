<implementer_rulings>
These rulings resolve the spec's silent/reconciled points. Apply them exactly; record each in the SUMMARY for author ratification — R-LOCCAP and R-HI03 additionally carry the spec's own "adopted ruling — veto point" tag so their ratification is unmissable.

- **R-LOCCAP (extent-capped presets)**: a per-dim LoC/K preset is feasible for a CONST extent only when `preset <= max(2, ceil(extent_d / T_d))`; non-const extents enumerate uncapped. Justification: §2.2's tie mechanics alone (traffic is LoC-neutral, descending-first) would select LoC=64 for the matmul M dim, but the §3.3 pin demands LoC=16 ("16 tiles, 16 CTAs all busy") — the cap is the only reading reproducing the pinned acceptance example, and `max(2, ...)` preserves CuMAP feasibility for tiny extents (>= 1 CTA dim always enumerable; the idle-CTA residue is the §9(d) accepted artifact). Needs const extents at search time: hoist a `constExtentOf(iter)` helper (ir.ConstValueOf over the BIV's bound operand — lower_rewrite.go extentOfBiv is the reference; share ONE helper).
- **R-DEFTILE (non-window default)**: non-window and non-spine iters default to SEQ with TileSize = max(TileSizes) — per-dim tiles are searched digits now, so there is no swept uniform tile; the max preset follows the §3.3 max-tile gradient. Every dim stays tiled >= 2 (2026-10-24 ruling preserved).
- **R-TRIPS (reuse trip counts, lane-aware per §2.4 "per-thread/per-lane interior walks")**: SEQ dim -> T_d; CTA dim -> ceil(T_d / blockDim); WARP dim -> ceil(T_d / 32) (the lane's chunk). blockDim = (Pi warp K_d) x 32 of the LNT (§1.2: coupledThreads := blockDim).
- **R-C1B (forced-FRAG pricing per §3.3)**: siteWindowBytes per covered dim — SMEM class: WARP -> K_d x T_d, SEQ -> T_d; FRAG class: SEQ -> T_d, WARP (C1b-forced) -> ceil(T_d / 32). FRAG bytes = Pi(covered factors) x sizeof, NO other lane division. Decide and lower MUST share this one function (fail-closed agreement).
- **R-SHARING**: cross-warp sharing = Pi over WARP-assigned dims NOT in the load's subscript set (== sf.INS) of K_d; 1 for FRAG sites. reuse = Pi(R-TRIPS over ReuseDims) x sharing; traffic avoided = bytes x (reuse - 1).
- **R-PARTITION**: partitionCount = 2 x (#CTA dims) + (#WARP dims) (expanded instances per §1.3, <= 6 under MAPM); selection key is lexicographic (traffic, partitionCount), both maximized, strictly-greater replaces, exact ties keep the first-enumerated (with LoC-descending digits this biases toward larger LoC).
- **R-EVICT**: per candidate against the running floors: while smemFloor+SumSMEM > MaxCache or fragFloor+SumFRAG > MaxFragPerThread, drop the promoted site with min density (density = reuse - 1; ties: smaller bytes first) to SiteDecision{Promoted: false, Reason: ReasonEvicted, Class/Reuse/Bytes retained}; loops stay tiled; empty result allowed with a warning (log facade or slog default — never an error).
- **R-HI03 (all three gates deleted)**: the double-writer premise is void under the new coupled walk (flat-rank init + step = blockDim is single-owner exact for ANY tile_max — the §3.3 pin itself requires T_M=256 > blockDim=128). Delete gate 1 (Params.Validate tile-vs-coupled), gate 2 (verify.go), gate 3 (lower_rewrite.go:445-455). tiling-verify's deletions list in §2.7 does not name HI-03 because §2.1/§2.3 never re-introduce it.
- **R-REDUCED (reducer-consumer detection)**: reducedIters(g) = union over live KindReduce nodes (HIR FamilyAbstract — visible at priority 114) of the iters referenced by the reduce's piped value input, chased with the existing findAxisIters-style Input chase. While p.ReducedDimWarp = false, WARP digits on those iters are pruned from the feasible area.
- **R-SEAM (lower*.go = mechanical only)**: see Task 1 step 5. The old templates stay; multi-CTA-dim / multi-WARP-dim LNT records fail closed with an error naming fix4 T4; GPU e2e is expected red between this plan and T6 and MUST NOT be run as a gate until then (old WARP shard walk + old runtime portion pre-conditions vs new records — TCACOMP_E2E tests skip hermetically, which is the gate).
