<objective>
Factor SM occupancy into the tiling search objective per the author-approved
locked design: `score' = traffic × (1 − idleFrac) × (ε + (1−ε)·fill)`. The
eviction loop, the constraint set, and the enumeration order are UNCHANGED —
occupancy scales only the final selection. Params grows six A6000/sm_86-pinned
fields; `schedResult.score` becomes float64; `better()` compares score' then
partism. Drifted test pins and goldens are re-pinned; the compiler is rebuilt
and the full GPU suite re-validated with a before/after benchmark comparison.

Purpose: the current objective is occupancy-blind, so the search happily
picks schedules whose grid vastly exceeds the useful parallelism (e.g.
LoC=64 on a nominal-4096 problem) — wasted CTAs, wasted launches, lost
occupancy. The occupancy factor makes the search prefer schedules whose grid
matches the (dynamic-shape, nominal-extent) problem size and whose CTAs
actually fill the machine.
Output: occupancy-aware search + re-pinned test suite + GPU-verified benchmark
delta recorded in STATE/SUMMARY.
</objective>
