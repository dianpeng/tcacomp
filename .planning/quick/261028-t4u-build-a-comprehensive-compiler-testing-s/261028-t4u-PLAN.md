- Stage chain per let: root map (on = >=1 tensor bindings) { | piped map (on() empty = pure elementwise, or re-bindings) | reduce(init=<typed const/capture expr>, on(acc, %0), as(surviving dims)) }* ; a kernel body = multiple letDecls + one return.

- reduce init must be a typed scalar constant/expression (dimvar init deferred); reduce requires >=1 live axis; chained reduces re-bind the input tensor in a NEW let (softmax shape).
- f32-only scalar typing in practice; single-expression lambdas; scalar captures for kernel scalar params; NO sub-kernel calls.
- piped map with tensor bindings (on(x[i][j], m[i])) is the documented form (rule 12/13) but is NOT yet exercised by a committed e2e — it is the main spike risk; fallbacks are documented per kernel below.
