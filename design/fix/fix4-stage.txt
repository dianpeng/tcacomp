============================================================

Spec: doc/fix/fix4.md (Wave 1 = T1-T7; Wave 2 = T8 split-k)

is green: build/vet/test pass, task commits landed, STATE.md row added.

  /gsd-quick --validate Implement doc/fix/fix4.md T1+T2 (decide pass + tiling-verify, §2)

--- Between-stage checkpoints -------------------------------------------

1. Stage 1 gates: unit tests per module green; the §3.3 matmul worked
   example pinned as a searcher expectation; determinism pins (fixed
   enumeration order: SoC, LoC DESCENDING, tile ASCENDING;
   first-strict-max) — do not let an executor "simplify" this.
2. Stage 3 gates: goldens byte-re-pinned in-commit (sanctioned churn,
   fix3 C11 precedent); expected signature: M=CTA / N=WARP / K=SEQ with
   BOTH matmul sites promoted at their caps (rhs's old decline is gone).
3. Stage 4 gates: numerical acceptance vs CPU reference on the A6000,
   sanitizer zero errors, zero-cache fixture emits a warning (not an
   error), doc pointer stubs committed.
4. Any stage may stop for an author ruling (the R-D pattern): read the
   SUMMARY.md, decide, then /gsd-quick resume <slug>.
